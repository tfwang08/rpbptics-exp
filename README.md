# Robotics experiment records

本仓库保存实验摘要与结论。每项实验记录说明研究问题、对照设置、评估口径、结果、可支持的结论及局限。

## 记录规则

- 仅提交人工整理的文字和汇总表；不提交训练、评估或数据处理代码，也不提交原始配置、日志、数据、模型权重或视频。
- 每项记录注明基础模型，并概括相对基线的实现或训练方法变化、改动目的和验证结果；模型结构、损失或微调策略的变化须单独标明，并与基线比较。
- 代码改动只写行为层面的文字摘要；不贴代码、具体文件名、差异片段、命令或内部接口细节。没有相关改动时也明确写出。
- 发布前检查内部组织与项目名称、绝对数据路径、服务器信息、账号、密钥、样本标识和其他可能指向内部资源的信息。
- 每项结果区分已完成的评估、仍待验证的问题和适用范围。后续实验完成后继续追加独立记录。
