# VLA / VLM 数据实验矩阵与推进顺序

设计版本：v1 · 2026-10-24  
范围：只做实验设计；本轮不盘点数据存量、不准备训练任务、不启动训练。下文数量是研究档位，不代表已经取得或验收的数据量。  
配套说明：[研究总方案与文献依据](2026-10-24-pi05-heterogeneous-data-sim.md)。

## 1. 研究目标与最终应得到的结论

系统研究 **数据规模 N、数据类型 T、训练采样配比 w** 对 VLA 和 VLM 的影响，并回答四个层次的问题：

1. **规律：**各种数据的收益怎样随规模增长，是否饱和；类型之间是否互补，最优配比是否变化。
2. **机制：**收益来自更多独立经历、更多任务/场景、动作监督、理解监督，还是仅仅更多训练计算。
3. **训练方式：**同样的数据在预训练、中训练、后训练及联合训练中怎样使用更有效。
4. **资源决策：**下一批数据或算力应投向哪里；什么条件下先训练 VLM 再训练 VLA 值得投入。

先以固定 π0.5 起点研究 VLA 的增量变化；流程可靠、首轮对照可解释后展开 VLM，并做 VLM→VLA 的受控迁移。VLA 的闭环评估仅使用仿真。旧三个任务保留为回归面板，不限制整个研究范围。

## 2. 先把五个容易混淆的量分开

| 量 | 定义 | 实验中如何使用 |
| --- | --- | --- |
| N：独立数据规模 | 按冻结规则定义并去重的轨迹/采集单元；视频操作片段保留共同采集祖先 | 规模实验改变 N，不能靠复制轨迹或提高帧率扩大 N |
| q：数据池组成 | 各来源在可用训练池中的份额 | 纯规模实验固定 q；类型替换实验可以改变 q |
| w：采样配比 | 实际进入训练的各来源样本份额，权重之和为 1 | 纯配比实验保持训练池不变，只改变 w |
| E：训练曝光 | 实际处理的窗口、图像、视觉/文本 token、有效动作监督及重复次数 | 判断是否只是反复使用少量数据，或稀释目标监督 |
| C：计算预算 | 固定硬件口径下的 GPU 小时，并补记有效计算、吞吐和总耗时 | 相同更新步数不自动等于相同 C |

例如，数据池有 100 万条 G、10 万条 D、10 万条 U、100 万条 H，采样可以各占 25%。它代表“对不均衡池做均衡采样”，不代表四类各有同样多的独立数据；少数来源会被重复更多。这个例子只说明概念，不是库存描述。

G/D/U/H 分别指机器人夹爪、机器人灵巧手、手持接口、人类 EGO。经典 UMI 与 DexUMI 保留子类；同源转换、重定向和回放保留祖先关系。一级来源不重复计数。来源类型、任务内容与监督类型分别标注。

N 是操作性计量，不意味着一条人类视频与一条机器人示范信息量相等。每组同时报告独立采集组、有效小时、窗口数、任务/场景覆盖和 token 数；跨类型关键对照再用有效时长或窗口预算复核。相邻片段的统计不确定性按共同采集组处理。

### 两条数据使用路线

- **控制实验路线：**构造组成、质量、内容覆盖尽量匹配的子集，用于识别 N/T/w 的作用。
- **全量利用路线：**允许来源规模不均衡，检验在大量可用数据和实际计算约束下如何训练最好。

控制子集的上限不是整个研究的上限。全量路线可以向更大规模扩展，但若 q、w 或任务覆盖同时变化，单列为“整体配方扩展”，不并入纯 N 曲线。

## 3. 三条主轴的正式假设

| 编号 | 可证伪假设 | 主要判别实验 | 如果不成立 |
| --- | --- | --- | --- |
| H1 | 相同配方下，增加独立数据在一定范围内提高迁移与泛化 | N×C 曲线 | 区分欠训练、冗余、质量下降和真实饱和 |
| H2 | 不同来源的规模收益不同，混合数据可能改变收益斜率 | 不同类型/配方各自的 N 曲线 | 使用更简单配方，保留未测规模边界 |
| H3 | 最佳 w 依赖 N、目标任务和训练阶段 | 两个规模及多个阶段的配比响应 | 在已测范围内采用稳定配比，减少后续调参 |
| H4 | 同 N 下，扩大任务/场景覆盖比重复相近内容更有利于外推 | 内容宽度×每类深度对照 | 根据目标任务保留深度，避免盲目增加类型 |
| H5 | U/H 与机器人数据存在互补，且互补依赖上游能力 | 来源组合与阶段交互 | 限制到有增益的任务或训练阶段 |
| H6 | M 能降低新机器人/技能族的 F 数据需求，且可被多个目标复用 | P→F 与 P→M→F，固定 F 及等总算力两种比较 | 跳过 M，或将其视为任务定向训练 |
| H7 | 对 VLM 有益的具身数据监督，也能改善 VLA 控制 | 同 VLM 起点的数据训练，再接同一下游动作训练 | 分别报告理解收益与行动收益，研究监督或接口瓶颈 |
| H8 | 最强单来源/小规模结论不一定在大规模混合中成立 | 保留组合、跨规模和最终独立确认 | 按条件给结论，不强求统一排序 |

假设用于安排对照，不预设一定能得到正收益或某个幂律。最终报告负迁移、无明显差异、收益饱和和条件依赖。

## 4. 规模与计算档位

### 4.1 VLA 数据规模

规划采用近似对数间隔：

| 档位 | 规划数据量 N | 用途 |
| --- | ---: | --- |
| N1 | 1 万个去重采集单元 | 小规模端，观察过拟合与高重复曝光 |
| N2 | 3 万 | 补充早期斜率 |
| N3 | 10 万 | 中规模参考点 |
| N4 | 30 万 | 检验转折和配比迁移 |
| N5 | 100 万 | 大规模端，区分数据不足与计算不足 |
| N6 | 300 万及以上 | 扩展段，在收益与计算需求值得继续时进入 |

这是设计目标，不以当前库存核实为本轮前提。将来实施时若需要平移整体范围，应在训练前保留至少三个跨度明确的档位并登记新绝对数值；不在看到结果后挑选横轴。

纯 N 实验在每个来源内部构造嵌套子集，固定 q、w 和筛选规则。同时保留“内容覆盖固定、每类增加轨迹”和“随 N 扩大内容覆盖”两种研究定义；二者分别作图，不能混称一个规模效应。

### 4.2 计算预算与复用

定义 Cref 为一种固定模型、输入规格和硬件口径的参考追加训练预算。其绝对 GPU 小时在真正准备执行时再测定；本轮不假设特定服务器或 GPU 配额。

首轮采用 Cref 与 4Cref 两个终点，另保留 0.25Cref 的早期诊断 checkpoint。对需要区分饱和与欠训练的大规模点，可增加 8Cref。较长预算仍未学稳时，不据此宣布数据没有价值。

若一个长训练的早期 checkpoint 用作短预算结果，各预算必须共享同一个优化前缀与数据顺序，称为“同日程截断比较”。不能把它冒充经过独立优化的短预算最佳模型。最终成本比较再给基线与候选相同的超参数选择预算。

模型参数量、输入分辨率、帧数、动作块长度、有效 batch 口径与优化方法在数据实验中固定；必要的接口变化另立对照。

## 5. 评估安排：先建立研究面板，再比较模型

### 5.1 开发与确认

- **开发面板：**6 个目标任务×机器人单元，至少 3 个技能族、2 种机器人配置，覆盖夹爪和多指接口。每个候选在相同 K=50 示范及 F 预算下适配。
- **扩展面板：**12 个单元，覆盖更多技能、物体和机器人，用于检查开发面板是否误导配方排序。
- **最终确认：**24 个单元的覆盖目标，至少 6 个技能族、4 种机器人配置；包含没有用于配方选择的任务族和机器人。数量是设计规格，具体环境实现留待执行准备时确定。
- 历史 Box/Drawer/Tray 单列回归；同一任务换多个手型不算多个独立技能族。

能力覆盖抓放/分类、关节物体、双臂协同、精确接触/装配、工具交互、长时序或组合任务；任务选取以研究能力为准。基准候选与环境验收原则见总方案。

任务包按基线难度分层，保留有区分度的中等与困难任务；若开发面板接近全成功或全失败，先创建新的面板版本并让所有对照重测，不能只给某一候选换任务。最终确认面板在查看候选结果前冻结。

开发每任务先用相同的 50 个配对场景筛选方向；扩展可增至 100，最终从每任务×种子 200 个场景起，根据预设效应和先导方差确定数量。小开发集不能支撑“微小提升稳定存在”的结论。

### 5.2 不同问题使用不同留出规则

| 协议 | 新增训练数据的限制 | 主要用途 |
| --- | --- | --- |
| A：已知任务新实例 | 允许同任务，隔离轨迹、采集会话和测试场景 | 保持能力与实例泛化 |
| B：全新任务族 | P/M 的所有新增来源排除该任务族 | 上游表征对新任务学习的帮助 |
| C：跨机器人技能 | 技能可出现在其他机器人，目标机器人该技能缺席 | 技能迁移 |
| D：新机器人 | P 排除目标机器人，M 可用其非目标任务 | 接口桥接与少样本适配 |
| E：来源独有概念 | 指定 U/H 可提供概念，机器人训练数据不提供 | 人类/手持数据的信息迁移 |

主规模与配比研究先采用一个共同的 B 留出协议；C/D/E 用独立协议复核关键结论。不能把含目标概念的 H 数据同时用于严格 B；不兼容的协议需要不同父模型，不能只换测试标签。

对任务标签无法可靠判断的新增数据，不声称它满足严格 B。S0 的原始预训练内容未知时，“未见”也仅指本项目新增数据。训练、验证和最终测试按原始采集祖先隔离，包括跨 VLM/VLA 的派生数据。

### 5.3 三层读数

1. 上游已有可执行接口的直接能力。
2. 使用统一 F 后的迁移成功率，以及关键模型的 K=10/50/200 嵌套示范曲线。
3. 相同总计算成本的完整路径结果，以及共享上游给多个目标使用时的摊销成本。

新机器人没有可执行接口时不报告零样本控制。先明确适配步骤，再统计其数据和计算成本。

## 6. VLA 第一批：规模×计算，而不是先凭感觉选比例

定义两个参考配方：

- **R：**G 与 D 的均衡参考；q 和 w 均为 50:50。
- **M4：**G/D/U/H 四来源均衡参考；q 和 w 均为 25:25:25:25。

均衡只是可解释的起点，不是推荐的最终比例。H 的监督类型在整个实验族内固定；无机器人动作标签的 H 使用其合法的辅助监督，不伪造机器人动作。

| 实验 ID | 设置 | 需要得到的结论 |
| --- | --- | --- |
| B00 | S0→F，6 个开发目标，K=50 | 不追加广域训练的共同基线 |
| S-R-N1/N3/N5 | R，三个跨数量级的 N，读取 Cref 与 4Cref 结果 | 机器人数据规模收益以及欠训练程度 |
| S-M4-N1/N3/N5 | M4，同三个 N 和计算终点 | 混合来源是否改变规模收益 |
| S-FILL-N2/N4 | 对关键配方补两个中间 N，先用 Cref | 检查转折，避免三点拟合出不可靠规律 |
| S-EXT-N6 | 有明确研究价值的配方向更大 N、必要的 C 扩展 | 检查更大规模能否保持收益 |

前六条上游训练轨迹均走到 4Cref，分别保存 Cref/4Cref，形成 12 个主要端点。早期 checkpoint 先作训练诊断，不必全部接完整 F。

在一个留出协议、一个探索种子下，这个核心包为：

- **6 条上游训练轨迹，合计 24Cref。**
- **12×6=72 个 F 分支，加 B00 的 6 个 F，共 78 个 F。**
- 额外复验、补点、多种子及其他留出协议另计；训练轨迹、checkpoint 数和下游训练数分别报告。

每个上游 checkpoint 的 F 规则完全相同。上游是否值得复用，看的是一组任务上的迁移收益，不能只凭 P 训练 loss 或某一个任务决定。

若大规模组只在 4Cref 改善，则报告数据与计算交互；若 Cref 和 4Cref 均无改善，继续结合内容/质量对照判断，不能立即宣布普遍饱和。

## 7. VLA 第二批：分开数据类型与内容覆盖

### 7.1 类型比较 T

选定共同的 Nref 与 Cref，保持总规模、优化和下游评估一致。类型实验允许改变来源池，尽量匹配任务族、场景和质量；无法匹配的因素在结论中保留。

| 实验 ID | 数据池与采样 | 用途 |
| --- | --- | --- |
| T-G / T-D / T-U / T-H | 单来源，各 Nref | 每种来源作为上游学习信号的能力边界 |
| T-R | 50% G + 50% D | 机器人参考 |
| T-RU | 40% G + 40% D + 20% U | U 的增量作用 |
| T-RH | 40% G + 40% D + 20% H | H 的增量作用 |
| T-RUH | 30% G + 30% D + 20% U + 20% H | U/H 的联合替换效果 |

这里 q=w，回答“等总数据规模和算力下，不同数据组合如何”。T-H 只通过统一 F 判断可迁移价值；不能要求只有人类监督的 P 直接输出有效机器人控制。

来源与监督本身不同，单来源排序只代表这套数据与合法监督组合的效果。发现 H 辅助训练收益后，补同辅助目标的机器人视频组，以及同 H 内容的不同监督版本，区分内容和目标函数。

T-R/T-RU/T-RH/T-RUH 保留完整组合，即使单来源收益弱也不删除联合组。该交互包含机器人份额下降的影响；出现组合优势后补固定外部总份额的单来源和双来源对照，再解释互补。

### 7.2 内容宽度与深度 D

在固定 N、q、w 和 C 下，优先在同一来源内构造：

| 实验 ID | 技能族覆盖 | 场景/物体覆盖 | 对应问题 |
| --- | --- | --- | --- |
| D-00 | 窄 | 窄 | 集中增加相近示范的参考 |
| D-10 | 广 | 窄 | 技能多样性是否有价值 |
| D-01 | 窄 | 广 | 环境与物体多样性是否有价值 |
| D-11 | 广 | 广 | 两种覆盖是否互补 |

各组数据量相同，因此广覆盖意味着每类示范更少。任务和场景的定义先冻结；训练和测试保持协议一致，不在看到结果后重新分组。

再选两个 N 对关键组重复，回答“数据丰富后应该加深已有内容，还是继续扩展覆盖”。这能把数据建设决策从“多收一些”转成明确的任务/场景分配。

机器人结构、任务相关性和真实/仿真来源另作小规模匹配对照。缺少可匹配单元时不能将来源差异单独归因于机器人形态。质量筛选也必须同时给等规模随机子集，避免把少数据与高质量混淆。

## 8. VLA 第三批：固定池上的配比响应面 W

本批固定 G/D/U/H 数据池及各自规模；只改变 w。它与第 7 节 q=w 的类型替换实验不同，不能因为权重数字相同就复用结果。

首轮使用 15 个有结构的配比点，覆盖四来源组成空间：

| 组别 | 配比规则 | 点数 |
| --- | --- | ---: |
| W-V | 四个单来源顶点：100/0/0/0 的四种位置 | 4 |
| W-E | 六种两来源组合，各 50:50 | 6 |
| W-F | 四种三来源组合，各占 1/3 | 4 |
| W-C | 四来源各 25% | 1 |

所有点为固定池下的采样实验，顶点自然只使用对应来源；这批结论是“给定数据池如何采样”，不声称已控制每组实际看到的独立数据量。记录 E、重复曝光和实际覆盖；再用类型匹配实验帮助解释。

15 点用于估计主要趋势和两两交互，可以拟合受约束的低阶响应面作为选点工具，但不能将平滑拟合图视为已测结果。每轮补 3–5 个新点，优先覆盖：预测较好区间、模型分歧较大区间、不同任务族发生冲突的区间。所有新点用真实训练与开发评估验证。

在更大 N 重测参考中心、两个候选及两个有诊断价值的点，共 5 点；若排序或最优区间变化明显，再补足该规模的 15 点。即使五点一致，也只报告这些配方在已测范围稳定，不声称证明了所有比例都不变。

最后引入一种自动权重方法，与最强静态配方比较，计算其学习权重成本；原始动作 loss 尺度不一致时不能直接用来调权。动态课程需匹配累计曝光后比较。主目标采用任务族宏平均，最弱任务族和保持能力作为约束，不用单个容易任务主导配方。

## 9. VLA 第四批：训练阶段与目标数据效率 P / M / F

### 9.1 中训练的有无和内容

选机器人参考 P 与候选 P 两个父模型，比较：

| 实验 ID | 路径 | M 的内容 |
| --- | --- | --- |
| M0 | P→F | 无 M |
| M1 | P→M-robot→F | 目标机器人的非目标任务，检验接口适配 |
| M2 | P→M-skill→F | 合法的相关技能数据，检验内容桥接 |
| M3 | P→M-both→F | 两者结合，保留固定广域回放 |

每组首先固定 F 的示范和预算，比较上游初始化价值；再给 M0 相同的端到端计算预算，判断 M 是否比延长其他阶段更值得。

若仍使用严格 B，相关技能数据也不能包含被排除的目标任务族；若研究“相同技能在另一机器人出现”，应转为 C 协议并重新准备父模型。改变研究问题时不能沿用原来的未见声明。

以两个 P、两种目标机器人计算，M1/M2/M3 新增 12 个 M 模型；它们接 6 个目标单元，连同 M0 一共形成 48 个 F 分支。M0 与此前条件完全相同的分支可以复用。该计数针对一个留出协议及一个探索种子。

对有收益的 M 配方补三个数据量档（例如 0.1×/1×/10×参考 M 数据量），并检查能否被多个目标任务复用。不能只在一个任务上提高成功率，就断言需要建立通用中训练阶段。

### 9.2 同一数据应该在哪个阶段用

分别选 U、H，比较“缺席、仅 P、仅 M、仅 F”，再增加一个由结果支持的跨阶段组合。固定原始数据池和全程累计监督曝光，调整出现的时间。不同阶段若同时改变学习率、冻结参数或辅助目标，先按整套配方报告，再拆解。

对关键组合比较 P→M→F、联合(P+M)→F、M→P→F，尽量匹配累计数据与总计算。每个优化顺序都是待验证假设，不能默认阶段越多越好。

### 9.3 后训练数据与样本效率

在相同上游 checkpoint 上比较：

- F0：目标任务单训。
- F1：目标数据加广域回放，回放份额候选 10%/30%/50%。
- F2：目标数据加任务相关 U/H；H 保留文献启发的 50:50 候选。
- F3：对有证据的组合，使用前期混合、后期目标集中的日程，与累计曝光相同的静态方案比较。

先在 K=50 找方向，再补 K=10/200；代表性目标可加入 K=1000 的高数据参考，检查上游收益在目标数据充足后是否消失。K 是目标机器人示范量，N 是上游数据规模，二者必须分开作图。K 子集嵌套；基础技能与来源独有概念协议分别处理。

## 10. VLM 实验：同样研究 N / T / w，使用独立评价

### 10.1 启动条件与数据口径

VLA 的数据划分、训练、动作适配和评估流程可靠，基线能够复现，且首轮数据对照可解释后，VLM 进入实际实验。现在只定义计划，不依赖完成 VLA 全部搜索。

VLM 的 N 按独立视觉内容计量，问答对数量另列；同一视频生成十个问题增加的是标注密度，不是十段新经历。独立采集组、图像/视频片段、有效小时和 token 曝光同时报告。数据生成与标注成本单列。

VLM 固定一个初始模型及输入规格。来源 G/D/U/H 保留，但监督任务另外划分：

- V-GEN：通用视觉语言与必要的通用语言回放。
- V-ROB：机器人状态、动作、子任务、成功/失败理解。
- V-HUM：EGO/UMI 的人—物交互和操作过程理解。
- V-SPT：空间定位、关系、接触、时间顺序等监督。

一个训练样本按主要监督任务进入一个采样桶，原始内容可产生多个样本但共享祖先与分割。先划分采集组，再生成训练标签。测试答案和评分规则独立；涉及下一步预测时不将未来答案片段作为输入。

### 10.2 VLM 的实验矩阵

| 实验 ID | 设置 | 核心问题 |
| --- | --- | --- |
| V-B0 | 原始 VLM，不追加领域训练 | 通用和具身理解起点 |
| V-S | 固定参考配方，规划 N 为 10万/30万/100万/300万/1000万个视觉内容单元；先做小/中/大三个点与两档 C | 理解能力的数据和计算响应 |
| V-T | 等 N/等 C 的 GEN、ROB、HUM、SPT，以及 GEN+具身组合 | 哪类内容和监督改善哪些能力 |
| V-D | 固定相同原始内容，对照描述、定位、时序/动作问题等标签；再固定标签密度扩展内容 | 标签更密与新内容更多，哪个更值得 |
| V-W | 固定池，先扫“通用:具身”100:0、75:25、50:50、25:75、0:100；再优化具身内部权重 | 专项收益与通用能力保持如何平衡 |
| V-ST | 同曝光的顺序训练与联合训练，关键配方再分阶段 | 数据顺序是否影响理解与后续迁移 |

各数量仍是设计档位。V-S 先使用一个固定参考配方，随后才为有代表性的不同类型/配方补规模曲线，不一次排列所有模型、标签和规模。

评估按视觉定位、空间关系、动作识别、时间顺序、任务进度/完成判断、步骤推理、通用能力保持分组。优先使用客观标签；开放式评分固定提示、模型版本与人工抽查规则。模型选择只用开发集。不能因为综合问答分数提高，就宣称执行能力提高。

## 11. VLM→VLA：相同经历，三种使用方法

固定一个可兼容的 VLM 起点、同一动作模块初始化和一套下游机器人训练协议：

| 实验 ID | 路径 | 作用 |
| --- | --- | --- |
| X0 | 原始 VLM→固定动作训练 | 共同基线 |
| X1 | 原始 VLM→额外通用视觉语言训练→同一动作训练 | 控制额外上游计算 |
| X2 | 原始 VLM→候选具身 VLM 训练→同一动作训练 | 判断具身理解训练的迁移 |
| X3 | 相同视觉语言与动作数据联合训练 | 比较同一批数据的联合与顺序用法 |
| X4 | 对有完整机器人动作的公共子集，直接将这些数据用于动作训练 | 比较“用于理解”与“用于行动”的价值 |

X0/X1/X2 的下游动作数据、适配步骤和预算完全相同；额外上游成本单列。X2/X3/X4 的整体成本比较还需匹配总计算与可用原始来源，记录不同标签覆盖和处理成本。H 没有机器人动作真值时，X4 不适用，不能伪造标签凑对照。

先选 2–3 个 VLM 配方接入仿真，其中至少包含一个明显改善具身理解的模型和一个数据量/计算匹配的控制。测试“理解更好但动作没有改善”的可能性；后续才定位视觉编码器、动作模块、时序信息或训练目标的问题。

π0.5 已训练权重的组件不能任意与其他 VLM 替换后作归因。若无法在 π0.5 中保持受控初始化，就用独立但各组相同的兼容适配轨道，先证明 X0 可有效训练；与 π0.5 继续训练结果分开报告。

## 12. 从开发到确认：保留什么，淘汰什么

### 12.1 搜索规则

- 每批先明确一个主效应或交互；只有初始化、数据清单、模型实现、优化规则、预算和评估协议均相同，才允许复用旧组。
- 来源无收益时，先检查监督、曝光、内容覆盖和预算；最多安排一个有明确诊断动机的修正对照，避免无限解释负结果。
- 短预算排名差异明显时，保留高预算验证；不能只选择早期收敛快的配方。
- 组合组、规模端点和无额外数据基线不能因首轮排名差而全部删掉。它们用于发现交互、负迁移和饱和。
- 候选要同时看任务族宏平均、弱项、保持能力和成本；小幅且不稳定的提升不扩大训练规模。
- 以开发集选择候选，最终确认后不继续针对同一最终集调参；扩展实验建立新版本的确认集。

文献已支持的接口原则作为默认；最接近本项目条件的关键结论做局部复验。具体对应表在总方案第 3 节，不把已有研究当作任意数据上的普遍定律。

### 12.2 结果怎样驱动下一批

| 观察 | 下一步 | 暂时不能下的结论 |
| --- | --- | --- |
| 大 N 在 Cref 没改善，在 4Cref 改善 | 优先研究计算分配与训练时长，再扩展数据 | 大数据无效或已经饱和 |
| 两个 C 下 N 都不改善 | 做等量内容/质量对照，并检查模型与评估瓶颈 | 所有类型的数据都不值得增加 |
| M4 只在大 N 超过 R | 优先补中间规模与来源交互 | 小规模来源排序可以外推 |
| U/H 单独弱，组合强 | 保留联合组，补固定外部总份额及 R 曝光对照 | 单来源无效所以组合必然无效 |
| 最优 w 随 N 或任务族变化 | 扩展对应规模的配比点，报告条件配方 | 存在唯一通用最佳比例 |
| M 提升统一 F，但不胜过等总算力基线 | 计算多任务复用能否摊薄成本，再决定保留 | 增加训练阶段本身提高效率 |
| VLM 理解提高，VLA 不改善 | 保留理解结论，做一个有动机的监督/接口诊断 | VLM 分数能替代闭环控制指标 |
| 候选只提高旧三任务 | 转入独立任务/机器人面板检查 | 获得普遍数据利用规律 |

每个决策还须考虑重复实验的不确定性和预先约定的最小有用提升。观察不明确时记录待验证，不为了推进阶段强行选赢家。

### 12.3 最终确认设计

基线加一个优胜配方，共 2 个方案，至少 3 个上游训练种子；对应 F 使用配对种子和嵌套目标示范。上游与下游随机性分层记录，不能把同一个 P 下多个 F 当成多个 P 重复。

- 24 个最终目标单元先全部测 K=50：2×3×24=144 个 F。
- 预先选定的 8 个代表单元补 K=10/200/1000：2×3×8×3=144 个 F。
- 合计 **288 个 F**，加相应的独立 P/M。若最终保留两个候选加基线，按同规则为 432 个 F。
- 这是完整确认包的设计规模；实际资源安排可分批完成，但已承诺的对照不能因结果不利被省略。未完成部分单独列出。

场景配对，按任务族、机器人和训练种子报告效果。失败保留在分母，基础设施异常按统一规则处理。只有少量任务族时，区间也不能证明对所有机器人任务成立。

## 13. 预算表与实验批次

预算先按 Cref、M 训练成本、F 训练成本和仿真评估成本管理；不编造当前可用 GPU 数或完成天数。

| 批次 | 核心配置数或规模 | 预算解释 |
| --- | --- | --- |
| VLA 规模核心包 | 6 条上游轨迹，12 主要端点，78 个 F | 上游 24Cref；F 与评估另计 |
| 类型包 | T 的 8 个设置，加必要的辅助目标控制 | 原则上 8Cref；完全相同的参考可复用 |
| 内容包 | 技能×场景 4 组，关键组跨规模复查 | 每个 N 为 4Cref；不要把样本数变化混入 |
| 配比包 | 中规模 15 点，大规模先 5 点，必要时扩到 15 | 每点先用固定预算；局部新点与自动配权另计 |
| M 包 | 例：12 个 M，48 个 F 路径 | 不把 1 个 M 与 1 个 P 当同成本 |
| 阶段/后训练包 | 按来源、阶段位置、K 和回放比例登记 | 先固定 K 找方向，再扩展 K 曲线 |
| VLM 包 | 小/中/大 N×两档 C，随后类型、标签与配比 | VLM 自己定义计算单位，不直接套用 VLA 步数 |
| 迁移包 | X0–X4 中适用的路径，2–3 个 VLM 候选 | 下游与端到端两个成本口径 |
| 最终确认包 | 基线+1候选：288 个 F，至少 3 个上游种子 | 独立父模型与最终评估成本全部计入 |

总预算按真实训练路径求和：上游共享一次，分叉训练分别计费；checkpoint 保存不算新训练，但接 F 和闭环评估有成本。数据转换、标注、自动配权和失败重跑分别记账。

数据丰富使我们能够扩大研究跨度，但计算投入仍需要围绕信息量安排。每批结果决定下一批补点、跨规模或机制实验；这份计划不要求把所有组合一次性全排列。
